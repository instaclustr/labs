# Baseline Vector RAG reference and source map

## Commands

Run from `scripts/baseline-vector-rag/` with the lab's `.venv` active.

| Make target | Equivalent command | What it does |
|---|---|---|
| `make install` | `python -m pip install -r ../../support/requirements.txt` | Installs the shared dependency set. |
| `make ingest` | `python -m src.ingest` | Splits the 260-recipe sample into 1,823 chunks, embeds them and indexes them into `recipes-vector-baseline`. `python -m src.ingest --recreate` drops the index first (the Makefile target passes no arguments); an index with the older one-document-per-recipe layout is replaced without it. |
| `make query QUESTION="..."` | `python -m src.query --question "..."` | Runs one kNN query and one LLM answer. Without `--question`, `src.query` asks both Fish and Chips questions. |
| `make validate` | `python -m src.validate` | Smoke test; prints four `[PASS]` lines (chunks fit the model and name their recipe; grouping counts recipes; hits and an answer came back; the documented retrieval gap reproduced). |
| `make clean` | — | Removes `__pycache__` and `.pytest_cache`. |

## Source map

These are the implementation files used by this task. When the overview and code differ, follow the current code and rerun the relevant check.

| File | Responsibility |
|---|---|
| [`Makefile`](../scripts/baseline-vector-rag/Makefile) | Install, ingest, query, validate, and clean targets. |
| [`src/__init__.py`](../scripts/baseline-vector-rag/src/__init__.py) | Makes `src` a package so modules run with `python -m src.<module>`. |
| `src/common` | Symbolic link to the shared [`support/common/`](../support/common/__init__.py) package. |
| [`src/ingest.py`](../scripts/baseline-vector-rag/src/ingest.py) | `main()` loads the recipes with `load_recipes()`, splits each with `chunk_recipe()`, embeds every chunk with `EmbeddingModel`, creates the index with `ensure_recipe_vector_index()`, and indexes each chunk (id = `chunk_id`). |
| [`src/query.py`](../scripts/baseline-vector-rag/src/query.py) | `ask()` embeds the question, runs `recipe_knn_search()` for `chunk_fetch(top_k)` chunks, folds them with `group_by_recipe()`, builds the context with `_build_context()`, and calls `generate()` under a "say I don't know" `SYSTEM_PROMPT`. |
| [`src/validate.py`](../scripts/baseline-vector-rag/src/validate.py) | `test_chunks_fit_the_embedding_model_and_name_their_recipe()` and `test_group_by_recipe_counts_recipes_not_chunks()` need no cluster; `test_baseline_vector_rag_returns_hits_and_answer()` asserts a non-empty answer and at least one hit; `test_baseline_vector_rag_drops_the_named_recipe()` asserts that the thegratefulgirlcooks.com question retrieves the womensweeklyfood.com.au recipe and not its own. |
| [`support/recipes/recipes_sample.json`](../support/recipes/recipes_sample.json) | The curated 260-recipe sample, including the ambiguous Fish and Chips pair. Shared by every task's `ingest.py`; the path is `RECIPES_SAMPLE_PATH` in `support/common/config.py`. |
| [`support/recipes/recipes_synthetic.json`](../support/recipes/recipes_synthetic.json) | Synthetic introduction, method and serving notes for each recipe, merged in by `load_recipes()`; regenerated by [`support/generate_synthetic_recipes.py`](../support/generate_synthetic_recipes.py) (optional). Not the original sites' text. |
| [`support/common/chunking.py`](../support/common/chunking.py) | `chunk_recipe()`, `load_recipes()`, `group_by_recipe()`, `chunk_fetch()`; splits a recipe into section chunks and folds ranked chunks back into recipes. |
| [`support/common/opensearch_client.py`](../support/common/opensearch_client.py) | `create_client()`, `ensure_recipe_vector_index()`, `recipe_knn_search()`, `normalize_hits()`. |
| [`support/common/embeddings.py`](../support/common/embeddings.py) | `EmbeddingModel` and `to_list()`. |
| [`support/common/llm_client.py`](../support/common/llm_client.py) | `generate()` for Bedrock or an OpenAI-compatible endpoint. |
| [Embedding models](../concepts/EMBEDDING_MODELS.md), [Chunking](../concepts/CHUNKING.md) and [BM25 versus kNN](../concepts/BM25_VS_KNN.md) | Concept pages with live probes behind this task. |
| [Troubleshooting](../troubleshooting/baseline-vector-rag.md) | Setup and runtime failures for this task. |
